Quizzy is a simple interactive quiz application built with React to test knowledge of React, JavaScript, HTML, and CSS. 
It includes 10 multiple-choice questions, shuffled question order, a 20-second timer for each question, score calculation, answer review, and a restart option. 
The app is built using React, JavaScript, HTML, CSS, and Vite, with a responsive design for different screen sizes.
Quizzy was created to practise React components, props, state management, hooks, and event handling.
